## 📌 Tentang Aplikasi

**UMKM Budget by Maxy Academy** adalah platform manajemen dan simulasi anggaran interaktif untuk pelaku Usaha Mikro, Kecil, dan Menengah (UMKM). Aplikasi ini dirancang oleh **Maxy Academy** untuk membantu UMKM merencanakan arus kas, memantau realisasi pengeluaran, serta memisahkan keuangan pribadi dan bisnis secara disiplin.

### Fitur Utama:
- 📊 **Dual Mode Finansial**: Pemisahan jelas antara mode Keuangan Pribadi dan Keuangan Bisnis.
- 🎯 **Rencana vs Realisasi**: Monitor deviasi anggaran vs realisasi secara real-time.
- 📱 **Dukungan PWA**: Dapat diinstal di desktop, Android, dan iOS serta berfungsi offline.
- 📑 **Export Laporan**: Unduh laporan lengkap dalam format PDF, CSV, dan Excel (XLSX).
- 💾 **Local Storage & Backup**: Simpan data aman di browser lokal dengan fitur backup/restore JSON.

## 🚀 Menjalankan Secara Lokal

**Prasyarat:** Node.js (v18+) & npm

1. **Install dependensi:**
   ```bash
   npm install
   ```

2. **Jalankan development server:**
   ```bash
   npm run dev
   ```

3. **Build untuk produksi:**
   ```bash
   npm run build
   ```
